    Adding more FCC frequencies?

    Click Import FCC database in this section and choose FCC_P25_USA.json or a smaller converted CSV/JSON. A large nationwide file is indexed locally by state; select a state to browse it. For exact transmitter pins, use a coordinate-enabled FCC JSON. The map status below shows how many sites have coordinates. Older JSON snapshots will show “Coordinates unavailable” until rebuilt and reimported. Do not select the original FCC ZIP.

    Ready to import a converted FCC database. Nationwide JSON files are processed in pieces and saved locally. Keep the original JSON as your backup.
    Looking for an active P25 transmitter?

    Select P25 sites (likely) to hide sites without P25 indications. Active FCC license + P25 narrows further, but an active license does not prove the site is transmitting. Verified on air only shows sites you have confirmed or imported with explicit on-air evidence.

    What's included: A small, explicitly labeled Pinellas public-safety starter selection from an FCC-derived directory. This is not a complete Florida or nationwide ULS database, and its license status and channel roles are not independently verified. To add more records, import a locally prepared FCC extract. Imported data remains offline in this browser. Keep your original nationwide JSON file as the backup; a large database export from this screen covers only the currently selected state. Browser storage depends on available disk space and may be removed if browser data is cleared.

    For CSV files, use the included FCC database converter or the CSV template. Expected fields include callsign, licensee, state, county, city and mhz.

    Get current FCC source data: FCC weekly archives → l_LMpriv.zip. Download once while online, convert it to a small state/county extract using the included helper, then import the resulting JSON here. The app itself needs no internet for searching or planning.

    Nationwide storage: To import a large JSON (such as 179 MB / 368,000 records), use Chrome or Edge with free disk space available. The app reads it in pieces and stores a state index locally. Search one state at a time; the original FCC_P25_USA.json is your nationwide backup. For small CSV/JSON extracts, the original importer still works.

    Starter source: Pinellas digital-frequency directory, reviewed November 6, 2026. Official verification: FCC ULS License Search.
