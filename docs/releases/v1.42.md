## Changes since v1.29
- Preserve all eight engineering workspaces and the embedded RF component catalog.
- Improve terrain timeout handling; add the FCC Class B booster registry, independent registry synchronization, database update coordinator, and combined RF map.
- Correct starter-only county coverage, failed refresh retention, P25 search/filter scope, statewide pagination, and automatic state downloads.
- Add independent, multi-state/multi-county FCC mapping, address/radius/band/text filters, donor paths, and combined KML export. Finder settings remain independent.
- Keep the weekly FCC transmitter and daily independent SBR publishing workflows unchanged. FCC licensing is not proof of on-air P25.
